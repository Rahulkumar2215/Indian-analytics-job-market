# Indian Analytics Job Market Intelligence

An end-to-end data science project that collects live analytics job postings from the Indian market, cleans and enriches them, and answers three practical questions:

1. **What is the Indian analytics market paying?** — by role family, seniority and city.
2. **Which skills actually carry a salary premium?** — demand vs. premium, skill by skill.
3. **What kinds of roles exist in the market?** — unsupervised segmentation into role archetypes.

Built as the capstone project for the Internshala Data Science PGC program.

## Key findings

> Numbers below are from my run of the pipeline (postings collected in 2026). Re-running the extraction will produce a different snapshot of the market.

| Finding | Result |
|---|---|
| Unique postings after cleaning | ~7,000 (from ~9,900 raw rows) |
| Postings that disclose a salary | ~20% |
| Highest skill premium | Machine Learning, ~+83% median salary vs. postings without it |
| Notable skill discount | Excel, ~−30% — widely requested, but associated with lower-paid roles |
| Market segments (K-Means) | 8 role archetypes, median salaries roughly ₹6.5L – ₹15L |
| Salary regression | Tested and **not** used — cross-validated R² was near zero |

**Why no salary prediction model?** Only about one in five Indian postings states a salary, and some of those figures are estimates generated by the job platform rather than stated by the employer. A regression trained on this data could not beat a simple average under cross-validation, so I report that honestly instead of presenting an unreliable model. The project leans on the demand-side analysis, the skill-premium comparison and the clustering instead.

## Pipeline

```
Adzuna Jobs API (India)  →  01_data_extraction.py  →  raw_job_postings.csv
                                                            │
                                                            ▼
                        02_cleaning_eda_modelling.ipynb  (cleaning → features → EDA → models)
                                                            │
                        ┌───────────────────┬───────────────┴───────────┬──────────────────┐
                        ▼                   ▼                           ▼                  ▼
            cleaned_job_postings.csv   figures/*.png          powerbi_dataset.csv     saved models
                                                                        │
                                                                        ▼
                                                              Power BI dashboard
```

### 1. Data collection — `01_data_extraction.py`
- Uses the official **Adzuna Jobs API** (`country = "in"`), the permitted access route for this data rather than scraping HTML.
- Two passes: a **national pass** across 14 analytics search terms, and a **city-scoped pass** over 10 major metros, because a single national query cannot page deep enough to collect enough unique postings.
- `BeautifulSoup` strips HTML from job descriptions.
- Retries with exponential backoff on rate limits and server errors; de-duplicates on `job_id` and on `(title, company, location)`.

### 2. Cleaning — notebook section 2
- Duplicate removal, text normalisation, date parsing.
- Salary midpoint from the advertised min/max band (all figures INR, so no currency conversion).
- Keeps Adzuna's `salary_is_predicted` flag so employer-stated and platform-estimated salaries can be separated.
- Winsorises salaries at the 1st/99th percentile instead of dropping rows, so postings still count in the skill and location analysis.

### 3. Feature engineering — notebook section 3
- **12 skill flags** (SQL, Python, Excel, Power BI, Tableau, R, Cloud, Big Data, ML, ETL, Statistics, Visualisation) from regex matching on title + description.
- **Seniority** (Entry → Leadership) and **role family** (Data Analysis, Business Analysis, BI/Reporting, Data Engineering, Data Science/ML) from job titles.
- **Metro and city tier** mapping, with NCR cities grouped under Delhi NCR.
- **Salary tier** ranked *within* each role family, so "high pay" means well paid for that role, not just "data engineering pays more than reporting".

### 4. Analysis and models — notebook sections 5–8
- EDA: salary distribution, market composition, pay by role/seniority/metro, **skill demand vs. skill premium** (the headline chart), hiring trend, top employers, correlation heatmap.
- **K-Means clustering** on skill profiles, with k chosen by silhouette score; clusters are profiled and named by their defining skills.
- **Role classifier from description text** (TF-IDF + Logistic Regression), with the posting's own title words removed from its description to prevent leakage.
- Salary regression and high-pay classification were evaluated against baselines; see *Key findings* for why the regression is not a headline result.

### 5. Dashboard — `dashboard/`
Power BI report built on `powerbi_dataset.csv`: KPI cards, Decomposition Tree, synced slicers, bookmarks and Row-Level Security.

## How to run it

**1. Clone and install**
```bash
git clone https://github.com/<your-username>/indian-analytics-job-market.git
cd indian-analytics-job-market
pip install -r requirements.txt
```

**2. Get free Adzuna API keys** at [developer.adzuna.com](https://developer.adzuna.com) and set them as environment variables (never paste them into the code you commit):
```bash
# Mac / Linux
export ADZUNA_APP_ID=your_app_id
export ADZUNA_APP_KEY=your_app_key

# Windows (Command Prompt)
set ADZUNA_APP_ID=your_app_id
set ADZUNA_APP_KEY=your_app_key
```

**3. Collect the data** (about 5–6 minutes, ~230 API calls — within the free tier)
```bash
python 01_data_extraction.py
```

**4. Run the analysis** — open `02_cleaning_eda_modelling.ipynb` in Jupyter or Google Colab and run all cells. If running in Colab, upload `raw_job_postings.csv` to the session first.

Outputs (cleaned CSV, Power BI dataset, figures, saved models) are written to the working directory.

## Limitations

- **Advertised ≠ offered salary.** Postings show what employers advertise, not what candidates are paid.
- **Low salary disclosure.** About 80% of postings have no salary, and part of the remainder are platform estimates.
- **Snapshot in time.** The data reflects postings live when the extraction ran.
- **Rule-based labels.** Skills, seniority and role family come from keyword rules on titles and descriptions; unusual job titles can be misclassified.
